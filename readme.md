# Brassage maison

Ce dépôt a pour objectif de m’aider à optimiser la fabrication de bière maison. Le brassage dépend de nombreux paramètres — ingrédients, équipement, procédé et fermentation — qu’il est utile de documenter pour mieux comprendre leur influence sur le résultat.

Les fichiers Markdown de ce dépôt constituent un contexte de référence pour échanger avec des agents d’intelligence artificielle et soutenir la création, l’adaptation et l’amélioration de recettes.
